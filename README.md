# Museo Web de la Evolución Gráfica

Proyecto terminado a partir del starter entregado.

- Abre `index.html` en un navegador.
- Las imágenes de `assets/` son diagramas locales de elaboración propia; cada una incluye crédito y fuente documental en la página.
- La sección de laboratorio incluye una calculadora RGB → HSV en JavaScript.
- El grupo queda como `________` para que el estudiante lo complete si corresponde.
